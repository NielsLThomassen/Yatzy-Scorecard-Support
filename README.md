# Yatzy Scorecard Support

Public support and privacy pages for **Yatzy Scorecard**, an iPhone and iPad app for keeping score in 5-dice and 6-dice Yatzy.

## Support

For support, questions, bug reports, or suggestions:

## Privacy

Yatzy Scorecard does not include third-party advertising, analytics, or tracking SDKs. Game data can be synchronized using Apple's iCloud and CloudKit services.
